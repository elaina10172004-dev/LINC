# CVRPTW Data

Named datasets used by the official entrypoints:

- `synthetic100`: `LINC_CVRPTW100_test_10k_seed1234.pt`
- `solomon56`: `solomon56.pt`
- `solomon50`: `solomon56_n50.pt` generated from the first 50 customers of
  each Solomon56 instance for ablation experiments.
- `homberger200`: `homberger200_60.pt`

`synthetic100` is generated by the LINC envelope/procedural CVRPTW generator and
contains 10,000 instances with 100 customers.

Solomon and Homberger files use the same serialized `.pt` dictionary format as
the synthetic set, including optional `names` and `bks_cost` fields when
available.
